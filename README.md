**Optimal Page Replacement Algorithm (≈100 words):**

The **Optimal Page Replacement Algorithm** is a page replacement technique used in operating systems to manage memory efficiently. It replaces the page that will **not be used for the longest period of time** in the future. This approach minimizes the total number of page faults, making it the best possible (theoretical) algorithm. However, it is **impractical for real-time systems**, as it requires **future knowledge of memory references**, which is not possible during execution. It is mainly used for **performance evaluation** and comparison with other algorithms like FIFO and LRU, providing a benchmark for the lowest achievable page faults.
